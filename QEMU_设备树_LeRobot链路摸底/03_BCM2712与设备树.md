# 03 BCM2712 与设备树

## BCM2712 是什么

`BCM2712` 是 Raspberry Pi 5 的主 SoC。对新 kernel 来说，它代表目标硬件平台：CPU、内存、中断、timer、PCIe、firmware/mailbox 等基础硬件都要围绕它初始化。

当前真机确认：

```text
/proc/device-tree/model      = Raspberry Pi 5 Model B Rev 1.1
/proc/device-tree/compatible = raspberrypi,5-model-b
                               brcm,bcm2712
```

## 设备树文件类型

```text
.dts   = Device Tree Source，板级设备树源码入口。
.dtsi  = Device Tree Source Include，被 include 的公共硬件片段。
.dtb   = Device Tree Blob，编译后的二进制，启动时真正交给 kernel。
dtc    = Device Tree Compiler，把 .dts/.dtsi 编译成 .dtb。
```

原则：

```text
第一阶段不改设备树。
新 kernel 应该先兼容并解析现有 Pi 5 dtb。
只有换板子、改外设接线、加 overlay/mock 设备时，才考虑改 dts/dtsi。
```

## Pi 5 设备树源码关系

```text
linux/arch/arm64/boot/dts/broadcom/bcm2712-rpi-5-b.dts   # Raspberry Pi 5 B 板级入口
  -> linux/arch/arm64/boot/dts/broadcom/bcm2712-ds.dtsi   # Pi 5 共享补充
     -> linux/arch/arm64/boot/dts/broadcom/bcm2712.dtsi   # BCM2712 SoC 本体
  -> linux/arch/arm64/boot/dts/broadcom/rp1.dtsi          # RP1 I/O 芯片
  -> linux/arch/arm64/boot/dts/broadcom/bcm2712-rpi.dtsi  # Raspberry Pi 公共配置
```

当前真机 dtb 和反编译文本已复制到：

```text
树莓派5真机文件快照/2026-05-18/boot/bcm2712-rpi-5-b.dtb
树莓派5真机文件快照/2026-05-18/boot/bcm2712-rpi-5-b.from-dtb.dts
树莓派5真机文件快照/2026-05-18/device-tree/proc-device-tree.tar
```

## 新 kernel 最少要理解的节点

| 节点 / 属性 | 中文含义 | 新 kernel 用它干什么 |
| --- | --- | --- |
| root `compatible` | 说明这是 `raspberrypi,5-model-b` / `brcm,bcm2712`。 | 选择 Pi 5/BCM2712 平台初始化路径。 |
| `memory@0` | 物理内存描述，bootloader 会填充。 | 建立物理内存管理。 |
| `chosen` | bootargs、console、initramfs 等启动信息。 | 拿 kernel cmdline 和 early console。 |
| `cpus` / `cpu@0..3` | 4 个 Cortex-A76 CPU。 | 初始化 CPU 拓扑。 |
| `psci` | ARM 固件调用接口，`method = smc`。 | 启动/关闭 CPU，重启等。 |
| `gicv2` | ARM GIC-400 中断控制器。 | 建立 IRQ 分发。 |
| `timer` | ARMv8 generic timer。 | 调度 tick、sleep、timeout。 |
| `reserved-memory` | ATF、CMA、bootloader 配置等保留内存。 | 内存分配器不能覆盖。 |
| `pcie2` | BCM2712 PCIe 控制器。 | RP1 通过这条 PCIe 接到 BCM2712。 |
| `rp1` | Raspberry Pi 5 的 I/O 芯片。 | 后续 USB/GPIO/UART/I2C/SPI 等都在 RP1 后面。 |
| `rp1_usb0` / `rp1_usb1` | RP1 上的 DWC3 USB host。 | 摄像头和舵机串口从这里枚举出来。 |

## 真机核对

| 对比项 | 真机结果 | 结论 |
| --- | --- | --- |
| root compatible | `raspberrypi,5-model-b`、`brcm,bcm2712` | 与设备树源码判断一致。 |
| USB aliases | `usb0 -> /axi/pcie@1000120000/rp1/usb@200000`，`usb1 -> /axi/pcie@1000120000/rp1/usb@300000` | RP1 USB host 链路成立。 |
| PCIe 到 RP1 | `/proc/device-tree/axi/pcie@1000120000` 是 `brcm,bcm2712-pcie`，`status = okay` | RP1 挂在 BCM2712 PCIe 后面。 |
| RP1 USB host | `usb@200000`、`usb@300000` 是 `snps,dwc3`，`status = okay` | 真实链路是 RP1 DWC3 host。 |
