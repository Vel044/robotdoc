# legacy_from_论文

本目录由 `robotdoc/论文` 合并而来，合并日期：2026-06-05。

合并规则：

- `robotdoc/undergraduate-thesis` 是正式论文目录。
- 与 `robotdoc/undergraduate-thesis` 已有文件同名相对路径的内容不搬入，本科论文工程保留后者版本。
- 本目录只归档旧 `论文` 目录中独有、且与论文写作、图片生成、文献整理或实验记录有关的材料。
- 本目录内容仅供回溯参考，不接入 `main.tex`、`chapters/`、`misc/` 等正式 LaTeX 编译链路。

已排除内容：

- `.DS_Store`、`.gitignore`、`.latexmkrc` 等目录/工具杂项。
- LaTeX 编译中间产物，例如 `*.aux`、`*.bbl`、`*.bcf`、`*.blg`、`*.fdb_latexmk`、`*.fls`、`*.out`、`*.run.xml`、`*.synctex.gz`、`*.toc`、`*.xdv` 和普通构建 `*.log`。
- 明显不属于本 LeRobot 论文的 `10007_毕业要求达成度计算系统*.docx`。
- 旧目录中与正式论文目录重复的章节 `.tex`、答辩附件、图片和模板文件。
