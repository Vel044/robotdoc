# 实验 06：ACT 推理管线逐模块耗时剖析

> 对应论文章节：第 3.2.4 节 单次 ACT 推理耗时分解
> 数据：`lerobot/analysis/06_act_inference_profiling/inference_timing.csv`（ACT 模型内直接写入）
> 分析与图：`lerobot/analysis/06_act_inference_profiling/`

## 一、实验目标

量化"队列为空时一次完整 `predict_action()` 的耗时分布"，定位推理瓶颈。
同时测量"队列非空快速路径"的耗时作为对照。

## 二、实验配置

| 参数 | 值 |
|------|-----|
| 硬件 | 树莓派 5（ARM Cortex-A76, 4 核） |
| 推理设备 | CPU（无 GPU） |
| 策略 | ACT，抓取瓶子 checkpoint |
| chunk_size | 100 |
| n_action_steps | 100 |
| 相机 | 两路 640×360, fps=30 |

## 三、测量方法

### 3.1 计时基础设施

在 `lerobot/src/lerobot/policies/act/modeling_act.py` 的 `ACTPolicy.__init__` 中初始化：
- `_PROFILING = os.environ.get("LEROBOT_PROFILING", "") == "1"`
- `_profiling_csv_path = os.environ.get("LEROBOT_PROFILING_CSV", "")`
- 启用后直接写 CSV 文件，不需要外部脚本注入

### 3.2 计时模块

| 模块 | 计时位置 | 说明 |
|------|----------|------|
| `full` | `select_action()`，队列为空时 | 完整推理（含 predict_action_chunk） |
| `resnet_backbone` | `ACT.forward()` 内，两路 ResNet18 + pos_embed + proj | 视觉特征提取 |
| `transformer_encoder` | `ACT.forward()` 内 `self.encoder(...)` | 视觉-状态融合 |
| `transformer_decoder` | `ACT.forward()` 内 `self.decoder(...)` | 动作查询解码 |
| `action_head` | `ACT.forward()` 内 `self.action_head(...)` | 动作输出 |
| `fast` | `select_action()`，队列非空时 | 只取缓存动作 |

### 3.3 输出 CSV 格式

```
run_id,path_type,module,time_ms
1,full,full,1234.567
2,full,resnet_backbone,892.345
2,full,transformer_encoder,234.567
...
99,fast,fast,0.045
```

## 四、运行命令

```bash
# 在树莓派 5 上跑正常 record，同时开启计时
LEROBOT_PROFILING=1 LEROBOT_PROFILING_CSV=/home/vel/lerobot/analysis/06_act_inference_profiling/inference_timing.csv \
    python -m lerobot.record \
    --robot.type=so101_follower --robot.port=/dev/ttyACM0 --robot.id=R12254705 \
    --teleop.type=so101_leader --teleop.port=/dev/ttyACM1 --teleop.id=R07254705 \
    --robot.disable_torque_on_disconnect=true \
    --robot.cameras="{'handeye': {'type': 'opencv', 'index_or_path': 0, 'width': 640, 'height': 360, 'fps': 30}, 'fixed': {'type': 'opencv', 'index_or_path': 2, 'width': 640, 'height': 360, 'fps': 30}}" \
    --dataset.single_task="Put the bottle into the black basket." \
    --policy.path=/home/vel/so101-bottle/last/pretrained_model \
    --dataset.repo_id=${HF_USER}/eval_so101_bottle --dataset.push_to_hub=false \
    --dataset.num_episodes=5 --dataset.episode_time_s=40 --dataset.reset_time_s=1 --resume=true

# 跑完后在 Mac 上分析
python lerobot/analysis/06_act_inference_profiling/analyze.py \
    --csv inference_timing.csv --outdir lerobot/analysis/06_act_inference_profiling
```
