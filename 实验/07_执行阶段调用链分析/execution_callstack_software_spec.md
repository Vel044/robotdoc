
## 一、图的用途

展示 `record.py` 的 `record_loop()` 一路下到 `scservo_sdk` 的 `PortHandler` 的完整 Python 软件栈调用链。
包含两路并行路径：`get_observation()`（读舵机）和 `send_action()`（写舵机）。

## 四、图内标注（关键数据点）

在节点旁边用小字号灰色文字标注：

| 标注位置                 | 内容                                                                                               |
| ------------------------ | -------------------------------------------------------------------------------------------------- |
| `get_observation()` 节点 | `sync_read("Present_Position")`，寄存器地址=56，长=2字节，bit15 sign-magnitude                     |
| `send_action()` 节点     | `sync_write("Goal_Position")`，寄存器地址=42，长=2字节，无回包                                     |
| Layer 2                  | 归一化：raw tick → -100~100 或 0~100；符号位编解码（bit15）                                        |
| Layer 3                  | 帧格式：读包 14 字节 `[FF FF FE 0A 82 ADDR LEN ID1..ID6 CS]`，写包 26 字节（6电机 × 3字节 + 包头） |
| Layer 3（读路径）        | 半双工总线，6 个舵机按 ID 顺序依次回包，每包 `[FF FF ID 04 ERR DATA_L DATA_H CS]`                  |
| Layer 3（写路径）        | 发完即返回，无回包，`is_using` 锁立即释放                                                          |
| Layer 4                  | 波特率 1 Mbps，每字节 ~0.01 ms                                                                     |
